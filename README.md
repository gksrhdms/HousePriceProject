housepriceproject 


1.
데이터셋을 불러와서 파악하기

집값변수를 확인 -> 좌측으로 치우쳐져 있음 확인

히트맵그래프로 집값변수와 가장 큰 상관관계를 가진 변수를 표시해서 확인

2.
가장 큰 상관관계를 가진 변수부터
이상치 제거하고, 로그를 씌워서 좌측으로 치우쳐져있던 것을 완화

3.
결측치 제거
(범주형 변수, 수치형 변수 나눠서 진행)
범주형변수 -> 결측치를 None이라는 문자열로 채우고
수치형변수 -> 결측치를 0으로 채움

4.
데이터 분석 과정에서는
새로운 몇 개의 변수를 만들어서, 총가용면적, 총욕실수 등의 변수로 각각 해당되는 변수들을 합쳐줌

집을 구매할 때 좋고 나쁨을 판단할 점수 변수도 새로 생성해서
각 대표 변수에 관한 변수들을 묶어서 마찬가지로 저장

비정상적으로 많거나 적은 변수들은 이상치로 간주하고 삭제햇음

5.
전처리
범주형 변수 같은 경우는 다짜고짜 숫자로 인코딩하면 머신러닝이 오해할 소지가 있기 때문에,
모조리 원핫 인코딩해줌(각 범주에 해당하는 고유한 벡터를 만드는 것)

수치형변수는 비대칭이 심해지지 않게끔 치우침이 심한 데이터들에만 log 씌우기

분석한 데이터 항목들을 데이터셋인 test 데이터의 갯수에 맞게끔 잘라서 따로 저장

6.
머신러닝 모델로 학습!
Lasso, ElasticNet, sklearn의 GradientBoosting, XGBoost 4개의 모델을 불러와서 저장

7.
예측 결과 저장 후 csv 파일로 생성 -> 제출 완료
